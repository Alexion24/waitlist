# Будьте в числе первых

Локальный лендинг со списком ожидания. Нужен Node.js 24 или новее. Установка зависимостей не требуется.

## Проверка на компьютере

1. Запустите `node app.js` и откройте http://127.0.0.1:3000.
2. Запишите один или несколько тестовых адресов. Адреса хранятся в `.data/waitlist.sqlite`.
3. Во втором терминале запустите `node app.js launch https://example.com`. Эта команда имитирует событие запуска. В локальном режиме письма появятся в `.data/outbox/` в формате `.eml`.
4. Обновите страницу. Вместо формы появится ссылка на запущенный сайт. Повторите команду с той же ссылкой, чтобы проверить, что рассылка не повторится.

Для чистого прогона задайте другое значение `WAITLIST_DATA_DIR` в обоих терминалах.

## Отправка при реальном запуске

При публикации основного сайта вызовите команду `node --env-file-if-exists=.env app.js launch https://ваш-сайт.example` после того, как он станет доступен. Команда автоматически разошлёт письма адресам из той же базы SQLite, которую использовал лендинг. Привязка команды к публикации зависит от будущего хостинга.

До запуска задайте `RESEND_API_KEY` и `EMAIL_FROM` в переменных окружения команды или в файле `.env`. В `EMAIL_FROM` укажите адрес с подтверждённого домена в [Resend](https://resend.com/docs/dashboard/domains/introduction). Без этих настроек команда сохраняет письма на диск.

Если отправка завершилась ошибкой, повторите команду с прежней ссылкой и настройками. Она обработает только адреса без отметки об отправке. При неопределённом результате запроса повторите его в пределах [24-часового окна Resend](https://resend.com/docs/dashboard/emails/idempotency-keys).
